# Naveen Ramkumar — Cybersecurity Portfolio

Responsive static website in a premium dark black/purple theme.

## Preview
Extract the ZIP and open `index.html` in a modern browser. No build tools or package installation are needed. Google Fonts are loaded online; fallback fonts are included.

## Included
- Responsive navigation and contact links for phone, email and LinkedIn
- About, competencies, project, education, experience and certifications sections
- Apple-inspired scroll reveal animations with reduced-motion accessibility support
- Resume-based details from the supplied resume

## Before publishing
- Verify all resume details and certification names/dates.
- The cloud-storage risk project description is based on the resume. Add a report or evidence link if you have one.
- The SOC alert-triage item is clearly labelled as a suggested future project, not completed work.
- Do not publish confidential employer or client information.

## Publish
Upload these files to a static hosting service such as GitHub Pages, Netlify or Cloudflare Pages. The site itself does not include a GitHub profile/contact section.
